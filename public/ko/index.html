Reach Check외부 접속 확인

다른 사람이 내 서비스에 접속할 수 있을까요?

전 세계 18개 지역(중국 3대 통신사 포함)에서 웹사이트, NAS, 게임 서버에 접속해 보고, 내 브라우저에서도 한 번 더 접속해요. DNS, TCP, TLS, 첫 바이트까지의 시간을 단계별로 보여 주고, 접속이 안 되면 막힌 단계와 다음에 확인할 것을 알려 줘요.

 

 

    전 세계에서

    DNSTCP 연결TLS 핸드셰이크첫 바이트다운로드

    데이터 출처: Globalping(jsDelivr가 운영하는, 자원봉사자들의 공개 측정 네트워크). 확인할 때마다 Globalping이 지역별로 측정 지점을 하나씩 골라요.

    내 브라우저에서

    브라우저는 HTTPS 요청만 보낼 수 있고 포트 상태를 볼 수 없어요. 요청이 얼마나 빨리 실패했는지로만 판단해요. 프록시를 쓰고 있다면 프록시 경로를 확인하는 거예요.

    DNS

    데이터 출처: AliDNS, Cloudflare, Google의 DoH. 브라우저에서 직접 조회해요.

    친구에게 확인 부탁하기

    이 링크를 친구에게 보내면, 친구의 브라우저에서 내 서비스에 접속해 봐요. 결과는 스크린샷이나 링크로 받으면 돼요.

    확인은 브라우저 안에서 실행돼요. Globalping을 직접 호출하고, 우리 서버를 거치지 않아요.
    데이터 출처: Globalping(외부 확인과 경로 추적), AliDNS·Cloudflare·Google(DNS), ipify와 IP.SB(내 IP).
