      よくある質問

      どうやってチェックしていますか？

      18 地域にある Globalping のボランティアの計測地点が、それぞれあなたのアドレスとポートに接続して HTTP(S) リクエストを 1 回送り、各段階の時間を測ります：名前解決、TCP 接続、TLS ハンドシェイク、最初の 1 バイト。失敗したときは、どこで止まったか（拒否、タイムアウト、リセット、TLS の問題、Web ページではないサービス）をエラーから判断します。

      あなたのブラウザからも接続します（表の 1 行目）。どれも私たちのサーバーは経由しません。

      自分では開けるのに、なぜ外からはつながらないのですか？

      サービスと同じネットワークにいると、通信は家の外に出ないので、自分で開けても外からつながる証拠にはなりません。プロキシを使っていると、ほかの人とは違う経路を通ることもあります。外部チェックの結果を基準にしてください。知らない人が接続するのと同じ方法でつないでいます。

      ポート転送を設定したのに、なぜタイムアウトするのですか？

      よくある原因：グローバル IPv4 がない（ルーターの WAN 側アドレスが 100.64〜100.127 で始まる、またはグローバル IP と違う：キャリアグレード NAT）。NAS、Windows、クラウドのセキュリティグループのファイアウォールが許可していない。プロバイダが家庭用回線の 80 番や 443 番を遮断している。転送先が機器の古いローカル IP のまま。

      IPv6 の場合は、ルーターの IPv6 ファイアウォールが外からの接続を遮断しているので、そのポートを許可してください。

      「拒否」と「タイムアウト」の違いは？

      拒否：パケットはマシンに届いたが、そのポートで待ち受けているプログラムがない状態です。サービスが止まっている、127.0.0.1 でしか待ち受けていない、または転送先のポートが違います。

      タイムアウト：まったく応答がない状態です。ファイアウォールがパケットを捨てている、ポート転送がない、またはアドレスが間違っています。

      ゲームや WireGuard の UDP ポートは確認できますか？

      できません。UDP のサービスは正しいメッセージを受け取らない限りふつう応答しないため、ブラウザからも公開の計測地点からも、UDP ポートが開いているかを確かめる汎用の方法がありません。まず TCP でホストにつながるか（SSH や Web のポート）を確認し、友だちにゲームから接続してもらってください。

      入力したアドレスは誰に見えますか？

      計測を行う Globalping です。私たちは保存しません。結果のリンクにはアドレスと結果が入っていて、ほかの人が同じ結果を見られます。あなた自身の IP は入りません。

      Globalping の利用枠は IP ごとに 1 時間 250 地域分で、1 回のチェックで 18 地域分を使います。使い切ると、いつ戻るかをページに表示します。
