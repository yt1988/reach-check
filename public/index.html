        Help

        How does the check work?

        Globalping's volunteer probes in 18 regions each connect to your address and port and send one HTTP(S) request, timing every step: DNS lookup, TCP connection, TLS handshake, first byte. When it fails, the error says where: refused, timed out, reset, a TLS problem, or a service that isn't a web page.

        Your own browser connects too: that's the table's first line. None of it goes through our servers.

        It opens for me. Why can't others reach it?

        If you're on the same network as the service, your traffic never leaves home, so opening it proves nothing about the outside. A proxy can also send you a different way from everyone else. Go by the outside check: it connects the way strangers do.

        I set up port forwarding. Why does it still time out?

        The usual causes: no public IPv4 (your router's WAN address starts with 100.64–100.127 or isn't your public IP: carrier-grade NAT); a firewall on the NAS, in Windows or in a cloud security group; the ISP blocking common ports such as 80 and 443 on home lines; or a forward that still points at the device's old local IP.

        With IPv6, the router's IPv6 firewall blocks incoming connections until you allow the port.

        What's the difference between refused and timed out?

        Refused: the packets reached the machine, but nothing listens on that port. The service is off, listens on 127.0.0.1 only, or the forward goes to the wrong port.

        Timed out: no answer at all. A firewall dropped the packets, there's no forward, or the address is wrong.

        Can it check UDP ports for games or WireGuard?

        No. A UDP service usually stays silent unless it gets the right message, so neither a browser nor a public probe can tell in general whether a UDP port is open. Check that the host is reachable over TCP (SSH or a web port), then ask a friend to join with the game itself.

        Who sees the address I enter?

        Globalping, which runs the probes. We don't store it. A result link holds the address and the result so others see the same check; it never holds your own IP.

        Each IP gets 250 region checks an hour on Globalping, and one check uses 18; when they run out, the page says when they come back.
