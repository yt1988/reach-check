        Questions fréquentes

        Comment fonctionne le test ?

        Les sondes bénévoles de Globalping, dans 18 régions, se connectent chacune à votre adresse et à votre port et envoient une requête HTTP(S), en chronométrant chaque étape : DNS, connexion TCP, négociation TLS, premier octet. En cas d'échec, l'erreur indique où : refusée, délai dépassé, réinitialisée, problème TLS, ou service qui n'est pas une page web.

        Votre propre navigateur se connecte aussi : c'est la première ligne du tableau. Rien ne passe par nos serveurs.

        Ça s'ouvre chez moi. Pourquoi les autres n'y arrivent-ils pas ?

        Si vous êtes sur le même réseau que le service, votre trafic ne sort pas de chez vous : l'ouvrir ne prouve rien pour l'extérieur. Un proxy peut aussi vous faire passer par un autre chemin que tout le monde. Fiez-vous au test extérieur : il se connecte comme le ferait un inconnu.

        J'ai configuré la redirection de port. Pourquoi le délai est-il toujours dépassé ?

        Causes habituelles : pas d'IPv4 publique (l'adresse WAN de la box commence par 100.64–100.127 ou n'est pas votre IP publique : CGNAT) ; un pare-feu sur le NAS, dans Windows ou dans un groupe de sécurité cloud ; l'opérateur qui bloque des ports courants comme 80 et 443 sur les connexions résidentielles ; ou une redirection qui pointe encore vers l'ancienne IP locale de l'appareil.

        En IPv6, le pare-feu IPv6 de la box bloque les connexions entrantes tant que vous n'autorisez pas le port.

        Quelle différence entre « refusée » et « délai dépassé » ?

        Refusée : les paquets sont arrivés à la machine, mais rien n'écoute sur ce port. Le service est arrêté, n'écoute que sur 127.0.0.1, ou la redirection vise le mauvais port.

        Délai dépassé : aucune réponse. Un pare-feu a jeté les paquets, il n'y a pas de redirection, ou l'adresse est fausse.

        Peut-il tester les ports UDP des jeux ou de WireGuard ?

        Non. Un service UDP reste en général muet tant qu'il ne reçoit pas le bon message : ni un navigateur ni une sonde publique ne peuvent savoir de façon générale si un port UDP est ouvert. Vérifiez que la machine est joignable en TCP (SSH ou un port web), puis demandez à un ami de se connecter avec le jeu lui-même.

        Qui voit l'adresse que je saisis ?

        Globalping, qui fait tourner les sondes. Nous ne la conservons pas. Un lien de résultat contient l'adresse et le résultat pour que d'autres voient le même test ; il ne contient jamais votre propre IP.

        Chaque IP dispose de 250 tests de région par heure chez Globalping, et un test en utilise 18 ; une fois épuisés, la page indique quand ils reviennent.
